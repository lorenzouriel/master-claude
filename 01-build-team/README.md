# Team 1 — The build team

**Plans it, then ships it.**

> Give Claude a plan before it writes a single line.

Seven plugins that put a thinking step in front of the typing step. They turn a rough
idea into a plan, keep the plan small, and make Claude test what it built.

| Plugin | Role | What it does | Stars |
|--------|------|--------------|-------|
| [Matt Pocock Skills](#matt-pocock-skills) | Senior dev | A pro coder's own skills, ready to copy | 325k |
| [Superpowers](#superpowers) | Planner | Makes Claude plan and test before it builds | 318k |
| [Ponytail](#ponytail) | Minimalist | Writes the least code that gets it done | 191k |
| [GStack](#gstack) | Manager | 23 tools that act like a startup team | 142k |
| [Security Audit](#security-audit) | Auditor | Multi-phase security audit with verified findings | 74k |
| [GSD](#gsd) | Project lead | Turns a rough idea into a step-by-step plan | 64k |
| [BMAD Method](#bmad-method) | Team coach | Runs a big build in small, planned steps | 55k |

---

## Matt Pocock Skills

`SENIOR DEV` · 325k

A working TypeScript educator's personal skill set, packaged so you can drop it into
your own setup. Use it when you want Claude to code the way an experienced developer
would rather than the way a tutorial would.

- **Repo:** [mattpocock/skills](https://github.com/mattpocock/skills)

## Superpowers

`PLANNER` · 318k

Forces a plan-then-verify loop: Claude writes out what it intends to do, builds it, then
tests the result instead of declaring victory. The default pick if you only install one
plugin from this team.

- **Repo:** [obra/superpowers](https://github.com/obra/superpowers)

## Ponytail

`MINIMALIST` · 191k

Biases Claude toward the smallest change that solves the problem — fewer files, fewer
abstractions, less scaffolding. Good antidote to AI over-engineering.

- **Repo:** [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)

## GStack

`MANAGER` · 142k

A bundle of 23 tools that behave like a small startup team: roles, handoffs, and a
shared process, rather than one assistant doing everything.

- **Repo:** [garrytan/gstack](https://github.com/garrytan/gstack)

## Security Audit

`AUDITOR` · 74k

Cloudflare's own skill: runs a security audit in phases and emits machine-readable
findings that are independently verified, so you get a checkable report rather than a
list of maybes. MIT-licensed. Worth a pass before anything goes to production.

- **Repo:** [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)
- Not part of the original five-team roundup — added on top.

## GSD

`PROJECT LEAD` · 64k

Takes a vague idea ("I want a dashboard for X") and returns an ordered, step-by-step
plan you can actually execute or hand off.

- **Repo:** [gsd-build/get-shit-done](https://github.com/gsd-build/get-shit-done)

## BMAD Method

`TEAM COACH` · 55k

A method for large builds: break the work into planned increments and run them one at a
time, so a big project never becomes one giant uncontrolled generation.

- **Repo:** [bmad-code-org/BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD)
