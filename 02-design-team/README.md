# Team 2 — The design team

**Makes it look good.**

> No more pages that look like every other AI page.

Seven plugins for taste and explanation: how the thing looks, and how you show other
people how it works.

| Plugin | Role | What it does | Stars |
|--------|------|--------------|-------|
| [UI UX Pro Max](#ui-ux-pro-max) | App designer | Gives Claude a pro eye for apps and sites | 150k |
| [Taste](#taste) | Art director | Stops your pages looking like generic AI | 116k |
| [Impeccable](#impeccable) | Design critic | Reviews the design and catches AI slop | 111k |
| [Archify](#archify) | Map maker | Turns any idea or plan into a diagram | 97k |
| [Understand Anything](#understand-anything) | Teacher | Explains any code with a map you can click | 93k |
| [Diagram Design](#diagram-design) | Illustrator | Draws 45 kinds of clean diagrams | 67k |
| [Excalidraw Diagram](#excalidraw-diagram) | Sketcher | Draws editable Excalidraw diagrams | 5.2k |

---

## UI UX Pro Max

`APP DESIGNER` · 150k

Design judgment for apps and sites — layout, hierarchy, spacing, states — so generated
interfaces hold up next to hand-designed ones.

- **Repo:** [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

## Taste

`ART DIRECTOR` · 116k

Targets the specific tell of AI-generated pages (the same gradient, the same card grid,
the same hero) and pushes the output somewhere with a point of view.

- **Repo:** [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)

## Impeccable

`DESIGN CRITIC` · 111k

Reviews a design rather than producing one. Run it after a build to catch the slop
before anyone else sees it.

- **Repo:** [pbakaus/impeccable](https://github.com/pbakaus/impeccable)

## Archify

`MAP MAKER` · 97k

Converts an idea or a written plan into a diagram, so the architecture is visible
before it is built.

- **Repo:** [tt-a1i/archify](https://github.com/tt-a1i/archify)

## Understand Anything

`TEACHER` · 93k

Explains an unfamiliar codebase through a clickable map instead of a wall of prose —
useful for onboarding and for reviewing code you did not write.

- **Repo:** [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything)

## Diagram Design

`ILLUSTRATOR` · 67k

45 diagram types, drawn cleanly and consistently. The workhorse when you need a
specific kind of chart rather than a general sketch.

- **Repo:** [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)

## Excalidraw Diagram

`SKETCHER` · 5.2k

Outputs real `.excalidraw` files rather than rendered images, so the diagram stays
editable in Excalidraw afterwards — the hand-drawn look, and you can move the boxes.
Pick this over [Diagram Design](#diagram-design) when someone needs to edit the result.

- **Repo:** [coleam00/excalidraw-diagram-skill](https://github.com/coleam00/excalidraw-diagram-skill)
