# Repurposing map

How one idea becomes platform-native pieces on LinkedIn, X, and Instagram.
Adapted from master-claude's social-content-planner; TikTok removed, Medium
added as the source.

## The principle

Each platform gets a different slice of the same idea:

| Platform | Gets | Why |
|---|---|---|
| Medium | The full proof: lab, measurements, price, the dare | The anchor. Everything else points back to it. |
| LinkedIn | The full argument with stakes and one receipt | Rewards depth, authority, and a personal moment |
| X | The sharpest line, or the compressed thread | Rewards punchy claims and scannable threads |
| Instagram | The visual structure: slides or a spoken Reel | Rewards saves and visual organization |

**Order:** Medium first (it forces the full idea), then LinkedIn, then the X
thread, then the Instagram carousel or Reel. When there is no article, the
LinkedIn post is the source and the order starts there.

**Stays the same everywhere:** the core claim, the most credible number or
named entity, the lesson, Lorenzo's point of view.

**Changes per platform:** the hook mechanism, length, format, CTA (LinkedIn:
comment; X: reply or bookmark; Instagram: save or "link in bio").

## Templates by idea type

### 1. Data or benchmark (a measured before/after)

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | F7 Odd-Precision Money / metric post | The exact number in line 1, full context below |
| X | T2 Number Shock | The number as the first word, one-line implication, link in reply |
| Instagram | Carousel, NUMBER layout cover | Cover = the number; one slide per layer of the breakdown |

Don't post the same paragraph three times. The number works on X because it
is all the context there is; on Instagram because it's structured visually.

### 2. Contrarian take (a tradeoff the article proved)

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | F10 Contrarian + Historical Receipts | Consensus, pivot, claim, steelman, evidence |
| X | T1 Contrarian or T4 Hot Take → thread | Bold claim in tweet 1; 5-7 tweet thread if it needs evidence |
| Instagram | Reel, Opinion format (or carousel) | Spoken claim in 0-3 s, steelman by 10 s |

### 3. Mistake or incident (Monday reflection material)

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | F4 Time-Anchor Confession | "N months ago I ..." as line 1; mistake, cost, lesson |
| X | T3 Confession | The same opening line plus the lesson, nothing else |
| Instagram | Single post, or Reel Story format | Start at the moment of maximum tension |

Compression: LinkedIn gets the full arc; X gets the opening line and the
lesson; Instagram gets the opening, the most relatable moment, and the lesson.

### 4. How-to or lab steps (Medium labs)

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | Carousel (PDF) or text post with steps, F8 or F5 opener | Outcome first, then the steps |
| X | T10 How-I thread | "How I [result] in [time]:" then one step per tweet, 140-180 chars |
| Instagram | Carousel step-by-step, or Reel Tutorial format | Cover: "How to [result] in [N] steps"; one step per slide |

### 5. Concept explainer (Tuesday diagram)

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | Post + the diagram image | The question the diagram answers, in line 1 |
| X | T8 Reveal + diagram image | "The real reason X happens is Y." with the diagram attached |
| Instagram | Carousel: diagram on slide 2, one component per slide after | Cover: the question |

### 6. Opinion on where the field is going

| Platform | Format | Entry point |
|---|---|---|
| LinkedIn | F5 Self-Proving Meta or F2 R.I.P. | Bold claim in line 1, vulnerability mid-post |
| X | T9 Thread Bait or T4 | "I've [done X] for N years. Here's what I think is true:" |
| Instagram | Reel, Opinion format | 45-60 s, end on the strongest line, no CTA |

## The Wednesday set (Medium recap day)

The standard spin-off set for an article, all on publish day except the
Thursday meme:

| Day | Piece | Module | Notes |
|---|---|---|---|
| Wed | LinkedIn recap post | linkedin-post | Link in the first comment |
| Wed | X thread | x-thread | Link in the last tweet |
| Wed | Instagram carousel recap | ig-carousel | "Full lab on Medium, link in bio" |
| Thu | Meme-format CTA (LinkedIn + Instagram) | linkedin-post / ig-carousel single post | Points back to Wednesday's article |
| Thu | X post with the article's sharpest insight | x-post | No link in the body; link in reply |

Later in the following weeks, insights the set didn't use become standalone
posts (different formulas, at least 3 days apart, interleaved with other
pillars).
