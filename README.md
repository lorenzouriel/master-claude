# master-claude

**32 Claude Code plugins, sorted into five teams.**

> Not a plugin. A directory of other people's plugins, with an opinion about each one.

Claude Code will happily install a hundred plugins and then feel like a hundred plugins.
This repo picks 32 and arranges them the way you would staff a small company: a team that
builds, a team that designs, a team that goes and finds things out, a team that produces
files other people can open, and a back office that tunes the assistant itself.

Each team is one page. Every entry says what the plugin does in plain English, who should
reach for it, and links to the repo it lives in.

## The Teams

| Team | Promise | Plugins | Most stars |
|------|---------|---------|------------|
| [01 — Build](01-build-team/) | Plans it, then ships it | 7 | Matt Pocock Skills · 325k |
| [02 — Design](02-design-team/) | Makes it look good | 7 | UI UX Pro Max · 150k |
| [03 — Research](03-research-team/) | Finds the answers | 6 | REA · 462k |
| [04 — Content](04-content-team/) | Videos, slides and words | 6 | Skills by Anthropic · 195k |
| [05 — Office](05-office-team/) | Keeps Claude sharp | 6 | ECC · 304k |

**[01 — The build team](01-build-team/)** puts a thinking step in front of the typing step:
turn a rough idea into a plan, keep the plan small, make Claude test what it built.

**[02 — The design team](02-design-team/)** covers taste and explanation — how the thing
looks, and how you show someone else how it works.

**[03 — The research team](03-research-team/)** goes and gets information, from the open
web, from your own files, or from a product you are trying to understand.

**[04 — The content team](04-content-team/)** produces a file you can send to someone — a
deck, a document, a video — rather than a message in a chat window.

**[05 — The office team](05-office-team/)** changes how every other session behaves: memory,
rules, token budget, output style. None of them build a product.

## Where to Start

Five picks, one per team, if you would rather not read all 32:

- **[Superpowers](01-build-team/README.md#superpowers)** · 318k — forces a plan-then-verify loop.
  The one to take if you install a single plugin from the build team.
- **[UI UX Pro Max](02-design-team/README.md#ui-ux-pro-max)** · 150k — design judgment for apps and
  sites, so generated interfaces hold up next to hand-designed ones.
- **[REA](03-research-team/README.md#rea)** · 462k — the most-starred plugin in the directory. Point
  it at an app and it reverse-engineers how the thing was built.
- **[Skills by Anthropic](04-content-team/README.md#skills-by-anthropic)** · 195k — the first-party
  set, and real `.docx`/`.xlsx`/`.pdf` output. The baseline the rest of that team builds on.
- **[ECC](05-office-team/README.md#ecc)** · 304k — skills, memory and security configuration in one
  pass. Start here if your setup has drifted.

## Using It

Nothing here installs itself. Open the team page, find the entry, follow the **Repo** link,
and install it the way that project documents — these are 32 independent repos by 32
different authors, not a marketplace with one command.

A few things worth knowing before you click:

- **Star counts are a snapshot**, not a verdict. The smallest entry in the directory
  ([Excalidraw Diagram](02-design-team/README.md#excalidraw-diagram), 5.2k) is the right answer
  whenever the diagram has to stay editable afterwards.
- **Licences and freshness vary.** Where a project has no declared licence or has gone
  quiet, the entry says so under its Repo link. Check before shipping anything commercial.
- **Two entries were added on top** of the original five-team roundup —
  [Security Audit](01-build-team/README.md#security-audit) and
  [Excalidraw Diagram](02-design-team/README.md#excalidraw-diagram) — and are marked as such.
- **Teams overlap on purpose.** [Humanizer](04-content-team/README.md#humanizer) and
  [Taste](02-design-team/README.md#taste) both exist to undo the same tell: output that reads and
  looks like every other AI output.
