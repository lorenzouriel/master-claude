# Team 5 — The office team

**Keeps Claude sharp.**

> They help Claude remember more and waste less.

Six plugins that tune the assistant itself: memory, rules, token budget and output
style. None of them build a product — they change how every other session behaves.

| Plugin | Role | What it does | Stars |
|--------|------|--------------|-------|
| [ECC](#ecc) | Ops manager | A full tune-up: skills, memory, security | 304k |
| [Karpathy Skills](#karpathy-skills) | Rule keeper | One rules file that fixes bad habits | 233k |
| [Caveman](#caveman) | Saver | Short replies, so your limit lasts longer | 120k |
| [Claude-Mem](#claude-mem) | Memory | Remembers your last chat for the next one | 117k |
| [I Have ADHD](#i-have-adhd) | Straight talker | Puts the answer first, every time | 61k |
| [Agent Skills](#agent-skills) | Handbook | The guide to building your own skills | 27k |

---

## ECC

`OPS MANAGER` · 304k

The broadest of the five: skills, memory and security configuration in one pass. Start
here if your setup has drifted and you want it straightened out.

- **Repo:** [affaan-m/ECC](https://github.com/affaan-m/ECC)

## Karpathy Skills

`RULE KEEPER` · 233k

A single rules file that corrects the common bad habits — over-explaining, unrequested
refactors, confident guessing. Small surface, large effect.

- **Repo:** [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)

## Caveman

`SAVER` · 120k

Clamps response length so a usage limit stretches further. Trades politeness for
tokens, deliberately.

- **Repo:** [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)

## Claude-Mem

`MEMORY` · 117k

Carries context from the last session into the next one, so you stop re-explaining the
project every morning.

- **Repo:** [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)

## I Have ADHD

`STRAIGHT TALKER` · 61k

Answer first, reasoning after — every time. Worth it if you keep scrolling past
preamble to find the actual result.

- **Repo:** [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd)

## Agent Skills

`HANDBOOK` · 27k

The guide to writing your own skills. Fewest stars here, but it is the one that lets you
stop installing other people's plugins and build your own.

- **Repo:** [agentskills/agentskills](https://github.com/agentskills/agentskills)
