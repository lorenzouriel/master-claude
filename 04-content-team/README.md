# Team 4 — The content team

**Videos, slides and words.**

> Real videos, real slides, real files. Not just chat.

Six plugins whose output is a file you can send to someone — a deck, a document, a
video — rather than a message in a chat window.

| Plugin | Role | What it does | Stars |
|--------|------|--------------|-------|
| [Skills by Anthropic](#skills-by-anthropic) | File maker | Makes real Word, Excel and PDF files | 195k |
| [HyperFrames](#hyperframes) | Video editor | Turns a web page into a real video | 85k |
| [OpenMontage](#openmontage) | Producer | A full video studio that Claude runs | 81k |
| [PPT Master](#ppt-master) | Slide maker | Turns any doc into a real PowerPoint | 77k |
| [Humanizer](#humanizer) | Editor | Removes the signs of AI writing | 69k |
| [Marketing Skills](#marketing-skills) | Marketer | Copywriting, SEO and growth, built in | 61k |

---

## Skills by Anthropic

`FILE MAKER` · 195k

The first-party set: genuine .docx, .xlsx and .pdf output rather than markdown that
looks like a document. The baseline everything else in this team builds on.

- **Repo:** [anthropics/skills](https://github.com/anthropics/skills)

## HyperFrames

`VIDEO EDITOR` · 85k

Turns a web page into a real video file — useful for demos, launch clips and anything
that needs motion instead of a screenshot.

- **Repo:** [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)

## OpenMontage

`PRODUCER` · 81k

A full video pipeline that Claude drives end to end, for when a single clip is not
enough.

- **Repo:** [OpenMontageInc/OpenMontage](https://github.com/OpenMontageInc/OpenMontage)

## PPT Master

`SLIDE MAKER` · 77k

Converts an existing document into a real PowerPoint deck, so the deck inherits the
structure of the source rather than being rewritten from scratch.

- **Repo:** [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)

## Humanizer

`EDITOR` · 69k

Strips the tells of AI prose — the triads, the hedging, the "it's not just X, it's Y"
constructions. Run it last, over finished copy.

- **Repo:** [blader/humanizer](https://github.com/blader/humanizer)

## Marketing Skills

`MARKETER` · 61k

Copywriting, SEO and growth playbooks packaged as skills, for when the writing has a
job to do beyond reading well.

- **Repo:** [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
